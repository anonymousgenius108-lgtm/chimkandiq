# EduConnect

Tutoring marketplace where students discover and book tutors by subject and availability, message tutors, manage bookings, leave reviews, and process demo payments. Also includes peer-to-peer Q&A, short-form learning Reels, a points/badges/leaderboard gamification layer, full student profiles with follow/followers, unified search, and a credits wallet.

The single demo user is "Alex Morgan" (avatar `https://i.pravatar.cc/200?img=5`), used everywhere actions are attributed to "the current user".

## Architecture

Pnpm monorepo with two main artifacts:

- **`artifacts/educonnect`** — React + Vite frontend (single-page app at root path `/`)
- **`artifacts/api-server`** — Express 5 + Drizzle ORM backend serving `/api/*`

Shared libraries:

- **`lib/api-spec`** — OpenAPI 3 contract (source of truth)
- **`lib/api-client-react`** — TanStack Query hooks generated by Orval
- **`lib/api-zod`** — Zod schemas for runtime validation generated by Orval
- **`lib/db`** — Drizzle ORM schema + Postgres client
- **`scripts`** — `pnpm --filter @workspace/scripts run seed` populates demo data

## Pages (frontend)

- `/` Discover (hero + featured tutors + subject browse)
- `/tutors` Browse with search, subject/day/rating/price filters, sort
- `/tutors/:tutorId` Tutor profile with About / Availability / Reviews tabs, review form, message + book actions
- `/bookings` Tabbed list (upcoming / completed / cancelled)
- `/bookings/:bookingId` Booking detail with payment dialog and cancel
- `/messages` Thread list
- `/messages/:tutorId` Conversation with simulated tutor replies (~3s polling)
- `/dashboard` Stats, weekly hours bar chart, top subjects, recent activity, level/points card
- `/notifications` Inbox with mark-as-read
- `/qna` Doubt Q&A list with search and Recent / Top / Unanswered tabs
- `/qna/ask` Compose a new question (title, body, 1–5 tags)
- `/qna/:questionId` Question detail with answers, voting, and best-answer marking
- `/reels` Vertical-video learning reels with like / comments / next-prev navigation and an "Up next" rail
- `/leaderboard` Daily / weekly / monthly / all-time rankings, your standing card, and the badge collection
- `/profile` Own profile (route also accepts `/profile/:userName` for any user) with header card, stats row, and About / Activity / Badges / Followers / Following tabs; non-self views show Follow / Unfollow + Message buttons
- `/search` Unified search (debounced, URL-synced `?q=`) across people, questions, reels, and tags with All / People / Questions / Reels / Tags tabs
- `/wallet` Credits wallet display: balance card, this-week and this-month deltas, full ledger history, and a Withdraw dialog (demo-only, no real money moved)

## Backend routes (`/api`)

- `GET /subjects`
- `GET /tutors`, `GET /tutors/featured`, `GET /tutors/:tutorId`
- `GET /tutors/:tutorId/reviews`, `POST /tutors/:tutorId/reviews`
- `GET /tutors/:tutorId/availability` (returns concrete next-2-weeks slots derived from weekly windows)
- `GET /bookings`, `POST /bookings`, `GET /bookings/:bookingId`, `PATCH /bookings/:bookingId`, `POST /bookings/:bookingId/pay`
- `GET /messages/threads`, `GET /messages/threads/:tutorId`, `POST /messages/threads/:tutorId` (auto-generates a tutor reply)
- `GET /notifications`, `POST /notifications/:notificationId/read`
- `GET /dashboard/summary`
- `GET /qna/questions`, `POST /qna/questions`, `GET /qna/questions/:questionId`
- `POST /qna/questions/:questionId/answers`, `POST /qna/questions/:questionId/vote`
- `POST /qna/answers/:answerId/vote`, `POST /qna/answers/:answerId/best`
- `GET /reels`, `POST /reels/:reelId/like`, `GET /reels/:reelId/comments`, `POST /reels/:reelId/comments`
- `GET /gamification/me`, `GET /gamification/leaderboard?period=…`, `GET /gamification/badges`
- `GET /profiles/me`, `PATCH /profiles/me`, `GET /profiles/:userName`
- `POST /profiles/:userName/follow`, `DELETE /profiles/:userName/follow`
- `GET /profiles/:userName/followers`, `GET /profiles/:userName/following`, `GET /profiles/:userName/activity`
- `GET /search?q=…` (returns users + questions + reels + tags)
- `GET /wallet/me`, `POST /wallet/withdraw` (records a negative `withdraw` row in `points_events`)

Payment is mocked — no Stripe. Posting to `/api/bookings/:id/pay` flips the booking to `confirmed` and returns a synthetic receipt.

## Database tables

`tutors`, `subjects`, `tutor_availability`, `reviews`, `bookings`, `messages`, `notifications`, `questions`, `answers`, `votes` (composite PK on target_type/target_id/user_name), `reels`, `reel_likes`, `reel_comments`, `badges`, `user_stats`, `user_badges`, `points_events`, `profiles` (PK `user_name`, plus display_name, avatar_url, bio, course, college, year_of_study, location, subjects/skills/interests/activities text[], is_private, joined_at), `follows` (composite PK `follower_name` + `followee_name`). See `lib/db/src/schema/`.

The credits wallet reuses `points_events` as its ledger — total credits = `user_stats.points` + sum of `points_events.points`. Withdrawals insert a row with `kind = "withdraw"` and a negative `points` amount; minimum withdraw is 100 credits, currency is INR.

Gamification levels: Beginner (0) → Learner (100) → Contributor (500) → Expert (1500) → Mentor (5000). Points are awarded by inserting a `points_events` row (askQuestion=5, postAnswer=10, bestAnswer=25, sessionCompleted=15, upvoteReceived=2). Asking and answering also create a `notifications` row when the recipient is not the current user.
