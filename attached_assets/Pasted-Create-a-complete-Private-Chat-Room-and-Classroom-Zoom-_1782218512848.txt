Create a complete Private Chat Room and Classroom Zoom-Style Meeting System for the education app.

This system should support private communication, live teaching, group learning, tutor meetings, student study sessions, and protected classroom spaces.

PRIVATE CHAT ROOM SYSTEM

Users can create private chat rooms for:

* Student groups
* Tutor-student discussion
* Coding teams
* Project teams
* Study groups
* Club members
* Course batches

Private room features:

* Invite-only access
* Room code / invite link
* Password-protected room option
* Admin approval option
* Member list
* Role permissions
* File sharing
* PDF sharing
* Voice notes
* Image sharing
* Pinned messages
* Search messages
* Save important messages
* Report system
* Block user option

ROOM ROLES:

* Owner
* Admin
* Moderator
* Member
* Guest

Owner/admin controls:

* Add members
* Remove members
* Mute members
* Lock room
* Delete room
* Change room privacy
* Pin announcements
* Control file uploads

Create a Zoom-style live classroom system inside the app.

Meeting types:

* Tutor live class
* 1v1 tutor meeting
* Group study meeting
* Coding classroom
* Doubt-solving room
* Club event
* Workshop
* Private mentoring session

MEETING FEATURES:

* Video call

* Camera on/off
* Participant list

* Host controls
* Co-host controls
* Attendance tracking
* Meeting recording
* Session notes
* File sharing
* Polls
* Breakout rooms
* Reactions

* AI class summary

HOST / TUTOR CONTROLS:

* Start meeting
* End meeting

* Mute all

* Assign co-host

WAITING ROOM SYSTEM:
Before joining, users enter waiting room.

Waiting room shows:

* Meeting title
* Host name
* Scheduled time
* Join status
* Camera/mic test
* Internet quality check
* Waiting message

Host can:

* Admit one user
* Admit all users
* Reject users
* Auto-admit verified students

ATTENDANCE SYSTEM:
Track:

* Join time
* Leave time
* Total time attended
* Participation score
* Poll response
* Chat activity
* Focus status optional

Save attendance to:
Tutor Dashboard → Class Analytics

RECORDING SYSTEM:
If host records meeting:

* Save recording inside tutor Store
* Allow tutor to share with students
* Students can save recording only inside:
  Profile → Store → Meeting Recordings

Downloaded recordings must remain inside app and work offline if allowed.
